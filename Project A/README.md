# OrbitalStation

Проєкт (частина А).

## Предметна область

**Система керування орбітальною станцією.** Станція складається з герметичних модулів
(житловий відсік, лабораторія, енергомодуль тощо), у кожному з яких є баки з ресурсами
(кисень, вода, пальне). На станції працює екіпаж. Система відстежує стан модулів і баків та
повертає список активних тривог (наприклад, рівень кисню нижче порога).

## Класи та інтерфейси

| Елемент | Призначення |
|---|---|
| `Station` | головний клас: модулі, екіпаж, тривоги |
| `Module` | модуль станції, містить баки |
| `ResourceTank` | бак з одним видом ресурсу |
| `CrewMember` | член екіпажу |
| `IMonitorable` | інтерфейс об'єкта, який можна моніторити |
| `ModuleType` | перелічення типів модуля |

## Правила предметної області

- Назва станції не порожня; назва модуля унікальна в межах станції; об'єм модуля додатний.
- В одному модулі не може бути двох баків з однаковим ресурсом; місткість бака додатна.
- `Consume` не може витратити більше, ніж є в баку; `Refill` не може перевищити місткість.
- Кількість для `Consume`/`Refill` додатна.
- Тривога бака: рівень нижчий за поріг (за замовчуванням 20% місткості); рівно на порозі тривоги немає.
- Тривога бака піднімається до модуля: модуль у тривозі, якщо хоч один його бак у тривозі.
- Призначити або перемістити людину в модуль можна лише через `Station.AssignToModule`:
  людина має бути в екіпажі станції, а модуль — у її складі.
